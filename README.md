## 📋 Markdown 格式规范（简要） | Syntax Quick Guide

- **姓名**：`# 你的姓名`
- **联系方式**：用 `|` 分隔，例如 `电话: xxx | 邮箱: xxx | 地址: xxx`
- **求职方向**：单独一行，放在联系方式下方
- **版块标题**：`# 教育背景`、`# 工作经历`、`# 技能背景` 等（一级标题）
- **条目标题**：`## 学校名称 | 学位 | 时间`（使用 `|` 分隔，自动识别为两栏或三栏，最多三栏）
- **列表项**：
  - `- 文本` 或 `* 文本` → 带圆点项目符号
  - `+ 文本` → **无项目符号**，顶格显示
- **加粗 / 斜体**：使用 HTML 标签 `<strong>` 和 `<em>`，不要使用 `**` 和 `*`

更详细的规范（共七章，含表格、代码示例、AI Prompt）请点击页面内的 **「格式规范」** 按钮查看。

- **Name**: `# Your Name`
- **Contact**: Use `|` as separator, e.g., `Phone: xxx | Email: xxx | Address: xxx`
- **Job Target**: Place on a separate line below contact info
- **Section Headings**: `# Education`, `# Work Experience`, `# Skills`, etc. (level-1 headings)
- **Entry Headings**: `## School | Degree | Date` – use `|` to separate fields (auto-detects 2 or 3 columns, max 3)
- **Bullet Points**:
  - `- text` or `* text` → with a bullet symbol
  - `+ text` → **no marker**, flush-left
- **Bold / Italic**: Use HTML tags `<strong>` and `<em>` instead of `**` and `*`

For full details (7 chapters with tables, code examples, and AI Prompt), click the **"Format Specification"** button inside the tool.

## 🛠️ 技术实现 | Technical Implementation

- 纯前端 HTML / CSS / JavaScript，无需服务器，零依赖。
- 使用 GitHub Pages 托管，即开即用。
- 所有数据处理均在浏览器本地完成，不收集任何用户信息。
- 照片通过 FileReader 转 Base64 本地存储，不上传服务器。
- 页边距通过 CSS 变量实时更新，分页计算预留 14mm 安全边距。

- Pure frontend HTML/CSS/JavaScript, no server, zero dependencies.
- Hosted on GitHub Pages – ready to use instantly.
- All data processing occurs locally in your browser – no user data is collected.
- Photos are converted to Base64 via FileReader and stored locally – never uploaded to any server.
- Page margins are applied in real time via CSS variables, with a 14mm safe margin reserved in pagination.
