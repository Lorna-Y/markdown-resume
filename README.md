## 📋 Markdown 格式规范（简要） | Syntax Quick Guide

- **姓名**：`# 你的姓名`  
- **联系方式**：用 `|` 分隔，例如 `电话: xxx | 邮箱: xxx | 地址: xxx`  
- **求职方向**：单独一行，放在联系方式下方  
- **版块标题**：`# 教育背景`、`# 工作经历` 等（一级标题）  
- **条目标题**：`## 学校名称 | 学位 | 时间`（使用 `|` 分隔，自动识别为两栏或三栏）  
- **列表项**：以 `-` 或 `*` 开头，例如 `- 负责活动策划与执行`

更详细的规范（共八章，含表格、代码示例、AI Prompt）请点击页面内的 **“格式规范”** 按钮查看。

- **Name**: `# Your Name`  
- **Contact**: Use `|` as separator, e.g., `Phone: xxx | Email: xxx | Address: xxx`  
- **Job Target**: Place on a separate line below contact info  
- **Section Headings**: `# Education`, `# Work Experience`, etc. (level‑1 headings)  
- **Entry Headings**: `## School | Degree | Date` – use `|` to separate fields (auto‑detects 2‑column or 3‑column layout)  
- **Bullet Points**: Start with `-` or `*`, e.g., `- Organized events with 200+ participants`

For full details (8 chapters with tables, code examples, and AI Prompt), click the **“Format Specification”** button inside the tool.
